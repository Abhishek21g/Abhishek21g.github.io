    What it checks

    Same plan → doctor → report discipline as other eval workbenches — applied to Delta partition reads.

    Partition manifest

    JSON with partition keys, per-file row counts, and schema dtypes.

    Memory estimate

    Peak bytes if every parquet file loads at once — the failure mode at scale.

    Batching recommendation

    Flags when to enable use_batching (maps to datarepo#49).

    Schema version hint

    Receipt slot for DeltalakeTable.at_version() when reading legacy data.

    Quick start

    git clone https://github.com/Abhishek21g/neural-data-partition-doctor
cd neural-data-partition-doctor

python3 partition_doctor.py doctor examples/small_partition.json
python3 partition_doctor.py doctor examples/large_many_files.json
python3 partition_doctor.py report examples/small_partition.json -o report.json
