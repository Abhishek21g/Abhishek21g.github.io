For teams shipping optimized ML models

Your model didn't crash. It drifted.

Faster compile paths (FP16, TensorRT) can change outputs without errors. This tool scans your model layer by layer, shows where numbers first go wrong, and recommends how to fix it — before anything hits the vehicle or production.

  • Works on standard ONNX models
  • No GPU required for the demo
  • Clear pass / fail verdict for CI

How it works

Three steps. No black box.

1

Scan

Run the model two ways — accurate reference vs optimized compile path — and compare every internal layer.

2

Pinpoint

See exactly which layer drifted first. The heatmap makes the failure obvious.

3

Fix & gate

Get suggested isolation rules and a ship/no-ship verdict you can wire into CI.

Try it in 60 seconds

Same scan shown in the live panel above.

pip install nuro-ftl-segment-receipts[onnx]

segment-receipts run examples/models/branch.onnx -o out/receipts
segment-receipts doctor out/receipts/<run-id>
open out/receipts/<run-id>/regression_report.html
