Multimodal Collections roundtrip audit

Receipts for upload → search → vision chat

Scripted harness for the xai_sdk.multimodal_collections workflow: store text with a local image path reference, search the collection, resolve paths from metadata, and verify vision-chat readiness — with a redacted audit log you can share.

demo · collections_multimodal_roundtrip

What the receipt captures

Each step is timed, status-coded, and redacted before export — paths and file IDs are masked.

Multimodal upload

UTF-8 text + image_path metadata via upload_multimodal_document().

Collection search

Hybrid/semantic search with match count and top score logged.

Path resolution

batch_get_documents + resolve_multimodal_search_results() fields-first.

Vision readiness

Validates inputs for multimodal_user_message() without leaking local paths.

Run offline demo or live roundtrip against your API key.
