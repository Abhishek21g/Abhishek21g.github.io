CLI — 60 second demo

Install from GitHub, run the bundled competitive-brief trace, and emit a receipt directory.

# install pip install git+https://github.com/Abhishek21g/epistemic-fork # plan fork at step 3 epistemic-fork plan --trace examples/competitive-brief.trace.json --fork-at 3 --json # run recency branch (mock) epistemic-fork run --trace examples/competitive-brief.trace.json --fork-at 3 \ --profile examples/recency-hour.alt.yaml --mock --run-id sample --out out/receipts # doctor + html report epistemic-fork doctor --receipt out/receipts/sample/ epistemic-fork report --receipt out/receipts/sample/ --html report.html
