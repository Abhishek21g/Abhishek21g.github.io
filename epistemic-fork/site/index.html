The problem Perplexity is solving

Mission

Trustworthy, cited answers from the live web — exposed to developers via Search API, Sonar, and the multi-provider Agent API.

Public pain

Agent loops call web_search across turns, but there is no open tooling to answer which search step flipped the conclusion when grounding diverges.

This product

plan → run → doctor → report on Agent API-style traces. Mock mode uses bundled fixtures — no Perplexity API key.
