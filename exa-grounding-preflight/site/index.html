Exa Grounding Preflight

Gate Exa-backed agent runs on retrieval completeness, citation/schema receipts, and empty or wrong-entity failure modes — before you trust the answer.

60s demo Six gates

CLI

Mock mode — no API key required. Plan → run → doctor → report.

$ pip install -e ".[dev]"
$ exa-ground run --mock --scenario examples/company-research.yaml --seed 42
$ exa-ground doctor --receipt out/receipts/company-research-pass/ --profile profiles/agent-search.yaml
$ exa-ground report --receipt out/receipts/company-research-pass/ --html

Doctor gates

Six invariants. Any fail → exit code 2. Receipts stay under out/receipts/.

non_empty_retrieval

Fail if zero search results.

schema_valid_structured_content

Structured monitor/answer content must be object or list when schema expected.

citation_coverage

Citations cover claim-count threshold.

auth_config_sanity

mock_mode OR api_key_present OR oauth_login_url — no live key probe.

entity_grounding_confidence

Founder-class entities must pass confidence/domain filter.

receipt_completeness

manifest.json + summary fields present.

Live receipt preview

Toggle pass vs fail modes — same gates, different fixture outcomes.
