What this is (and isn't)

Not a world model

We don't train LeWM or V-JEPA. This is ML systems tooling — the preflight kit researchers run before MPC / CEM planning on released checkpoints.

LeWorldModel paper

Maes et al. (LeCun co-author): stable JEPA from pixels, fast latent planning, and surprise evaluation — physically implausible latent jumps get flagged. Preflight implements that gate + config doctors.

AMI alignment

AMI Labs builds controllable, safe action-conditioned world models. Public vjepa2 issues show silent crop_size / pred_depth mismatches — this catches them first.
