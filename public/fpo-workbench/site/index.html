One loop for FPO++ training trust.

The workbench turns a log directory and agent YAML into an inspectable receipt — paper baseline grade, cliff detection, flow dynamics, and checkpoint manifest in one trail.

  1. 01 Plan

    Flag pre-run risks: EMA decay, learning epochs, iter budget vs paper-tuned 2k G1 runs.

  2. 02 Run

    Ingest metrics.jsonl, checkpoints, and hyperparams into a versioned receipt dir.

  3. 03 Doctor

    Four signals: reward cliff, KL spike, surrogate proxy, obs-norm drift + baseline grade.

  4. 04 Report

    Emit manifest.json, doctor.json, and report.md under out/receipts/.
