The impossible problem (made mockable)

Mission

Starlink operates the world's largest LEO constellation. SpaceX publicly hires for automated collision avoidance, SSA, and orbit determination at fleet scale.

Public pain

Job posts describe screening thousands of conjunctions, maneuver decisions, and CI-grade automation — but no open receipt toolchain exists for replaying CDM streams with auditable gates.

This product

plan → run → doctor → report on synthetic scenarios. Independent of community Starlink monitoring PRs. Receipt JSON a hiring manager can inspect in 60 seconds.

CLI

pip install git+https://github.com/Abhishek21g/constellation-conjunction-workbench

conjunction-wb plan  --scenario scenarios/demo_leo_cluster.yaml --json
conjunction-wb run   --scenario scenarios/demo_leo_cluster.yaml --cdm fixtures/demo_conjunction.cdm.json
conjunction-wb doctor --receipt out/receipts/<run-id>/receipt.json --json
conjunction-wb report --receipt out/receipts/<run-id>/receipt.json
