SIA Eval Harness · v0.1

Receipts for self-improving AI runs

SIA optimizes both the harness and the weights in one loop. This tool compiles a finished runs/run_* tree into a portable receipt — separating harness gains, weight gains, and overfit residue without re-running evals.

hexo-ai/sia read-only compiler not sia web MIT

The problem

After a SIA run, you get results.json, improvement.md, and agent code diffs — but no single artifact that answers: was this gain from code, from weights, or from task-specific cheating? The feedback loop can also inherit eval integrity bugs (held-out labels leaking into prompts — #36).

What the harness does

  • Harness vs weights — detects --focus mode and attributes metric Δ accordingly
  • Leak check — flags gold-label keys in results.json
  • Overfit signal — surfaces transfer_evidence.json residue when present
  • Repro — SHA-256 hashes of key generation artifacts
