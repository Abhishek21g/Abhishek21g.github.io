How the solution works

1
SIA run

sia run --task longcot-chess writes runs/run_1/gen_*

↓
2
sia-eval compile

Read-only walk — no re-run, no fork of SIA

↓
3
Run receipt

Harness Δ vs weights Δ · leak check · overfit residue · artifact hashes

Separates three things SIA’s loop mixes together: harness improvements, weight tuning, and task-specific overfit.

The product (source code)

sia-eval-harness/

sia_eval_harness/
├── cli.py          ← sia-eval compile
├── compiler.py     ← receipt builder
├── checks.py       ← leak + metric + focus
└── schema.py       ← receipt v0.1
demo/runs/run_1/    ← bundled demo run
tests/              ← 4 pytest tests
  • Input: any runs/run_* tree from SIA
  • Output: receipts/run_*.json + .md
  • Detects focus: target_agent.py → harness, train.py → weights
  • Leak guard: flags expected, reference_answer, etc. in results
  • Transfer evidence: reads transfer_evidence.json when present
Open source repo

Run it yourself

$ git clone https://github.com/Abhishek21g/sia-eval-harness.git
$ cd sia-eval-harness && pip install -e ".[dev]"
$ sia-eval compile demo/runs/run_1 # bundled demo — no API keys needed
$ sia-eval compile runs/run_1 # after your own SIA run

Writes demo/runs/run_1/receipts/run_1.json and run_1.md
