SIA_Eval_Harness.demo

Open-source side project · v0.1

Receipts for self-improving AI runs

I built this to show something SIA’s loop doesn’t ship today: a read-only compiler that turns a finished runs/run_* folder into a receipt — what improved (harness vs weights), whether eval leaked gold labels, and what looks like overfit.

my build hexo-ai/sia ecosystem not sia web

Why I made it

SIA runs produce results.json, improvement.md, and agent diffs — but nothing ties them together. After working on upstream PRs for hexo-ai/sia, I wanted a demo that answers: was the score jump from code, from weights, or from task-specific residue?

What it checks

  • Harness vs weights — reads --focus mode from artifacts
  • Leak guard — flags gold-label keys in results.json
  • Overfit signal — pulls transfer_evidence.json when present
  • Repro — SHA-256 hashes of generation files
$ sia-eval compile runs/run_1 # → receipts/run_1.json + run_1.md
