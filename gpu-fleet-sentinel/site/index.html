Four signals. Zero fluff.

Mapped to the Observability / Validation bullet — not generic infra monitoring.

PCIe link degradation

Compares max_link_gen vs current_link_gen and link width. Gen5→Gen3 is a silent bandwidth cut.

Thermal throttling

Flags hw_thermal_slowdown / sw_thermal_slowdown Active — clocks drop, apps keep running.

ECC errors

Uncorrectable → quarantine. Rising volatile correctable → early hardware warning.

NVLink health

Inactive links and CRC / replay / recovery counters that break multi-GPU scaling.

plan → run → doctor → report
