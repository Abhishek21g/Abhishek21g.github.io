Doctor verdicts

ALL_PASS           — contracts OK
AUTH_BLOCKER       — OAuth / scopes (not your agent)
LATENCY_BLOCKER    — timeouts (known MCP pain)
AGENT_CODE_ISSUE   — JSON / schema drift in your harness
MIXED_FAILURES     — inspect per-step receipts
